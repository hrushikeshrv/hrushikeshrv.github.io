# hrushikeshrv.github.io
## Development
Run `npm run dev`. This will watch any changes in any HTML, CSS, JS, or JSON files in the project directory and rebuild `index.html`.

**IMPORTANT**  
Make all your edits to `index.html` in `index.template.html`. `index.html` is auto-generated by `build.mjs` by injecting `index.template.html` with the right data.

After making your changes, simply push them since `index.html` will already have been updated.

**NOTE**  
The dev server _DOES NOT_ build any files other than `index.html`. This assumes that your content is only that one single page.
